# gameflowplayz.github.io

Official portfolio website for GameFlowPlayz – showcasing Minecraft Bedrock visual packs including shaders, UI, PvP, and X-ray tools.

Includes a landing page and dedicated project pages for each pack, with download links to CurseForge and MCPEDL.

---

## Structure

- `index.html` – Home page
- `projects/` – Individual project pages
- `assets/` – Images, banners, favicon, icons

---

## Local Setup

Clone the repo and open `index.html` in your browser. For best results, use a local server (Live Server in VS Code or `python -m http.server`).
